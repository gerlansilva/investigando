# Para quem desenvolve

Tecnologias: Tauri 2, React, TypeScript (modo estrito) e Vite.

Comandos (na pasta do projeto):

- `npm install` instala as dependências.
- `npm run dev` abre no navegador, em http://localhost:1420.
- `npm test` roda os testes automáticos.
- `npm run tipos` confere os tipos.
- `npm run construir` gera a versão de produção.

Instaladores: aba **Actions → Instaladores → Run workflow** no GitHub, ou publicar uma etiqueta `v*`. O fluxo gera o `.dmg` (Mac) e o `.exe` e `.msi` (Windows).
